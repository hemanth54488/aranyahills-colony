# User Guide

## For Residents of Aranya Hills Colony

Welcome to the Aranya Hills Colony Welfare Association website. This guide explains how to use all features.

---

## Getting Started

### 1. Register Your Account

1. Go to https://aranyahillscolony.in
2. Click "Register" in the top-right corner
3. Fill in the form:
   - Full Name (your real name)
   - Phone Number (10-digit mobile)
   - Plot Number (select your plot from dropdown)
   - Email Address (used to login)
   - Password (minimum 8 characters, must include uppercase and number)
   - Confirm Password
4. Click "Register"
5. Wait for the Secretary to approve your account
6. You will receive an email once approved

### 2. Login

1. Go to https://aranyahillscolony.in/login
2. Enter your email and password
3. Click "Login"

## Features Available to All (No Login Required)

### Home Page
- View colony statistics (total plots, occupied, vacant)
- See current committee members
- Read latest notices
- Find emergency service contacts

### Committee Page
- See all 6 committee members with their roles
- View contact details (phone, email)
- Browse past committees by year

### Notices Board
- Read all colony announcements
- See urgent notices highlighted in red
- Filter by general/urgent/event

---

## Features After Login (Approved Residents)

### Plots & Residents Directory
- Browse all 26 plots
- See which plots are occupied/vacant
- Search by plot number or resident name
- Filter by status (Occupied/Vacant/Under Construction)
- Click any plot to see detailed information

### Plot Detail Page
- View house photo
- See family members
- Open location in Google Maps
- View owner contact details

### Colony Information (Restricted)
- Bank account details
- PAN card number
- Official bylaws
- Important documents

### Service Providers
- Find plumbers, electricians, carpenters, etc.
- One-click call button
- Add new service providers
- See availability status

## Language Settings

The website supports 3 languages. Switch at any time:
- Click the language button (EN / TE / HI) in the top-right of the navbar
- Select your preferred language
- All text changes immediately

Languages available:
- EN: English
- TE: Telugu (ananya hills)
- HI: Hindi

## Common Questions

### I registered but cannot login?
Your account is pending approval from the Secretary. Once approved, you will receive an email. If it has been more than 2 days, contact the Secretary.

### I forgot my password?
On the login page, click "Forgot Password?" and enter your email. You will receive a password reset link.

### My plot is showing wrong information?
Contact the Secretary to update plot details. The admin manages plot information.

### How do I change my language preference?
Click the language button (EN/TE/HI) in the top navigation bar and select your preferred language.

### The website is not loading?
1. Check your internet connection
2. Try refreshing the page (Ctrl+R)
3. Try a different browser
4. Contact the Secretary if the issue persists
